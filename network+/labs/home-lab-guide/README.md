# Home-Lab Guide

The cumulative, hands-on network you build with your own gear as you progress
through the course. Each stage unlocks after a specific module (see the
[Curriculum Roadmap](../../docs/CURRICULUM-ROADMAP.md#integrated-home-lab-track)).

**Your equipment:** Windows laptop · Dell PowerConnect 3424 managed switch ·
home router · Ethernet cables.

| Stage | You build | Unlocked after | Status |
|-------|-----------|----------------|--------|
| LAB-A | Wire and test your first Ethernet link | Module 06 | Planned |
| LAB-B | Log into the Dell 3424 and tour it | Module 07 | Planned |
| LAB-C | Plan your home IP scheme and subnets | Module 08 | Planned |
| LAB-D | Watch DHCP/DNS work on your router | Module 09 | Planned |
| LAB-E | Create and test VLANs on the switch | Module 11 | Planned |
| LAB-F | Add inter-VLAN routing and wireless | Module 11 | Planned |
| LAB-G | Document and secure the network | Modules 12–13 | Planned |
| LAB-H | Break it and fix it (troubleshooting drills) | Module 14 | Planned |
| LAB-CAP | Full capstone build from scratch | Module 15 | Planned |

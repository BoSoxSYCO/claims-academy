# NetworkAcademy+ Glossary

Every **bolded key term** taught in the course, defined in plain language at a ~7th-grade
reading level. Terms are added as lessons are published. Each entry notes the lesson that
first teaches it.

**How to use this:** if you meet a bold word in a lesson and forget what it means, look here.
If a word isn't here yet, it hasn't been taught yet — and no lesson uses a term before it's defined.

---

## C

- **Computer** — A machine that follows instructions to turn input into useful output. *(First taught: NA-M01-L01)*

## H

- **Hardware** — The physical parts of a computer that you can touch. *(First taught: NA-M01-L01)*

## I

- **Input** — Information you put into a computer, such as typing, tapping, or clicking. *(First taught: NA-M01-L01)*

## M

- **Memory** — Where a computer holds the information it is working on right now. (Covered in depth in NA-M01-L02.) *(First named: NA-M01-L01)*

## O

- **Output** — The result a computer gives back, such as words on a screen, a sound, or a printout. *(First taught: NA-M01-L01)*

## P

- **Processing** — The work a computer does by following its instructions. *(First taught: NA-M01-L01)*
- **Program** — A set of instructions that tells a computer what to do. *(First taught: NA-M01-L01)*

## S

- **Storage** — Where a computer saves information to use later. (Covered in depth in NA-M01-L02.) *(First named: NA-M01-L01)*

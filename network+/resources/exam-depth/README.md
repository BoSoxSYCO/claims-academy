# Exam-Depth Supplements

Short, focused add-ons that take seven exam objectives **past** the beginner lessons to full exam depth. The main 96-lesson course teaches every one of these topics at a beginner level; these supplements add the extra detail CompTIA can test. Read them during exam prep, after you've finished the related module.

Three of these objectives had only passing mentions in the core lessons (marked **gap-filler** below); the other four were taught at a "summarize" level and are lifted here (marked **depth add-on**).

| Supplement | Objective | Type |
|------------|-----------|------|
| [Cloud concepts and connectivity](supplement-1-3-cloud-concepts.md) | 1.3 | gap-filler |
| [Modern network environments](supplement-1-8-modern-network-environments.md) | 1.8 | gap-filler |
| [Physical installation factors](supplement-2-4-physical-installation-factors.md) | 2.4 | gap-filler |
| [Networking appliances and functions](supplement-1-2-networking-appliances.md) | 1.2 | depth add-on |
| [Routing technologies (dynamic routing)](supplement-2-1-dynamic-routing.md) | 2.1 | depth add-on |
| [IPv4 and IPv6 network services](supplement-3-4-ipv4-ipv6-services.md) | 3.4 | depth add-on |
| [Network access and management methods](supplement-3-5-access-management-methods.md) | 3.5 | depth add-on |

Each supplement follows the same shape: **why it matters**, key words, the depth content in tables, 🎯 exam tips, and a short quick-check with answers. Every bolded key term is in the [glossary](../glossary/glossary-all.md).

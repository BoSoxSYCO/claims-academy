## Core concepts (Module 13)

| Q | A |
|---|---|
| CIA triad | Confidentiality, Integrity, Availability |
| AAA | Authentication, Authorization, Accounting |
| Least privilege | Give users only the access they need |
| Multifactor authentication (MFA) | Two or more different proofs of identity |
| Which control serves Confidentiality / Integrity / Availability | Encryption / hashing (checksums) / backups & redundancy |

## Attacks & threats (Module 13)

| Q | A |
|---|---|
| Phishing | A fake message that tricks you into giving up secrets |
| On-path attack | Attacker secretly relays/alters traffic between two parties |
| DDoS | Flood a service so it can't respond |

## Defenses (Module 13)

| Q | A |
|---|---|
| Firewall default-deny | Block everything not explicitly allowed |
| Screened subnet (DMZ) | Isolates public-facing servers from the internal network |
| Hardening examples | Change default passwords · disable unused ports/services |
| First thing to change on new gear | The default password |
| Reduce the "attack surface" by… | Turning off unused services/ports (hardening) |

## Secure access & data (Module 13)

| Q | A |
|---|---|
| VPN | A private, encrypted tunnel over a public network |
| Remote-access vs site-to-site VPN | One user's device vs two whole networks/offices |
| Protect data in transit | Encrypt it (HTTPS/TLS, VPN) |

# Teaching Notes — NA-M02-L02 "Finding and Opening the Tools You'll Use"

> 🔒 Instructor materials. Pairs with the lesson and `wb-02-02-answers.md`.

## Objective in one line
Learners can open any Windows tool by searching and pin favorites to the taskbar.

## Where this sits
Second lesson of Module 02. Removes friction before the command-line lessons: learners must be able to open Command Prompt quickly. Time: ~20 min + ~40 min worksheets/lab.

## The anchor
The **building-directory analogy** and the muscle-memory habit: **Windows key → type name → Enter.**

## Common misconceptions (and the fix)
- "I must memorize where each tool lives." → Fix: just search by name.
- Typing before focusing Start. → Fix: press the Windows key first, then type.

## Pacing tips
- Have learners repeat the search habit several times until it's automatic.
- Ensure everyone pins Command Prompt — the next lessons depend on it.

## How CompTIA tests it
Indirect: every hands-on task begins by opening a tool. Speed here compounds across all later labs.

## Support ideas
- Practice opening five tools in a row by search; celebrate the speed-up.

## Extension ideas
- Pin the whole course toolkit (Command Prompt, Task Manager, Settings) to the taskbar.

# Teaching Notes — NA-M02-L03 "Meet the Command Prompt and PowerShell"

> 🔒 Instructor materials. Pairs with the lesson and `wb-02-03-answers.md`.

## Objective in one line
Learners can open a terminal, read the prompt, and run a safe command, understanding the rhythm.

## Where this sits
Third lesson of Module 02. First real terminal exposure — the gateway to the networking command tools in 02-04. Time: ~25 min + ~40 min worksheets/lab.

## The anchor
The **texting analogy** (type an exact message → press send → get a reply) and the fixed **rhythm**: prompt → command → Enter → output.

## Common misconceptions (and the fix)
- Typing the prompt text (`C:\Users\You>`) along with the command. → Fix: type only what comes after `>`.
- Expecting a pop-up window instead of text output. → Fix: output appears as text right below.

## Pacing tips
- Keep the commands to `ver` and `whoami` (both harmless). The real network tools come next lesson (02-04).
- Reassure anxious learners: nothing here can break the computer.

## How CompTIA tests it
By naming CLI tools and their output. Comfort in the terminal is the prerequisite for every command-line exam objective.

## Support ideas
- Narrate the rhythm aloud on each command: "prompt, type, Enter, output."

## Extension ideas
- Try `hostname` and `time /t` (safe) and identify the output.

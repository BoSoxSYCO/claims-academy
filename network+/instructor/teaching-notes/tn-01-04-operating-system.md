# Teaching Notes — NA-M01-L04 "What an Operating System Does"

> 🔒 Instructor materials. Pairs with the lesson and `wb-01-04-answers.md`.

## Objective in one line
Learners can explain what an OS does and recognize that network devices run one too.

## Where this sits
Fourth content lesson. Ties together the hardware from 01-02/01-03 under a single "manager." Plants the crucial seed that the Dell switch and home router each run an OS you configure later (Modules 07, 11). Time: ~25 min + ~40 min worksheets/lab.

## The anchor
The **three-layer picture** (You + apps → OS → hardware) and the **restaurant-manager analogy** (extends the Lesson 01-01 kitchen).

## Common misconceptions (and the fix)
- "Windows = the computer." → Fix: Windows is software (the OS) running on the hardware.
- "Programs use hardware directly." → Fix: programs ask the OS; the OS uses the hardware.
- "Only PCs have an OS." → Fix: phones, routers, switches all run one.

## Pacing tips
- The `winver` lab is quick — the real payoff is the learner saying their OS name aloud and grasping that their switch has an OS too.
- Don't go into kernels/processes; keep it at "the manager."

## How CompTIA tests it
Framing switches/routers/firewalls as configurable systems that run an OS. Reinforce every time such a device appears later.

## Support ideas
- Act it out: one person is the OS relaying requests from "apps" to the "hardware."

## Extension ideas
- List the OS on every device in the home; note how many are Linux-based.

# Teaching Notes — NA-M07-L05 "Meet the Dell PowerConnect 3424 (Managed Switch)"

> 🔒 Instructor materials. Pairs with the lesson and `wb-07-05-answers.md`.

## Objective in one line
Learners tell a **managed** switch from an **unmanaged** one and name the Dell 3424's front-panel parts (access ports, uplink/Gigabit ports, SFP slot, console port, LEDs).

## Where this sits
Fifth lesson of Module 07 — the first hands-on look at the learner's real switch. It builds on hub/switch/router (07-01) and MAC learning (07-02), and it sets up the **first login** in 07-05's follow-up (07-06). This is **Lab B, part 1** (tour only — no login yet).
Time: ~28 min + ~40 min worksheets/lab.

## The anchor
**Two ovens:** a basic on/off oven (unmanaged switch) vs. a smart oven with a full control panel (managed switch). Both cook (forward frames); only the smart one gives controls a pro needs.

## Common misconceptions (and the fix)
- "The console port carries network traffic." → Fix: it is management only (serial), for the first login.
- "Any switch can be configured." → Fix: only a **managed** switch can be logged into.
- "Access port = uplink port." → Fix: access = where devices plug in; uplink = faster link up to a router/core.
- "Managed changes how the switch forwards." → Fix: it still learns MACs and forwards the same way; managed only **adds** login and configuration.

## Pacing tips
- The tour-your-switch lab (7.5.E) is the payoff and preps the 07-06 login — give it time.
- Drill the four parts out loud: access / uplink / console / SFP.

## Accuracy note (Prime Directive #7)
Exact Gigabit/combo/SFP port counts and LED colors/blink patterns **vary by unit and firmware**. The lesson flags these as `[TO VERIFY ON HARDWARE]`. Do not state a specific count or LED behavior as fact until it is confirmed on the learner's actual 3424.

## How CompTIA tests it
Managed vs. unmanaged switches; switch features (VLANs, monitoring, remote management); port and console-port roles (objectives 2.1 and 2.3).

## Support ideas
- Re-use the two-ovens analogy for any "why managed?" question.
- Let a struggling learner just point-and-name parts before worrying about "why."

## Extension ideas
- Stacking, firmware versions, and out-of-band vs. in-band management for fast learners.

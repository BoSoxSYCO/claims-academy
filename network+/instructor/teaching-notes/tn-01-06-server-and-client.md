# Teaching Notes — NA-M01-L06 "What a Server and a Client Are"

> 🔒 Instructor materials. Pairs with the lesson and `wb-01-06-answers.md`.

## Objective in one line
Learners can explain client vs. server, request vs. response, and that a server is a computer with a job.

## Where this sits
Sixth and final lesson of Module 01 — the bridge into Unit 2 (real networking). Everything on a network is a client asking a server, so this pattern recurs constantly. Time: ~20 min + ~40 min worksheets/lab.

## The anchor
The **waiter analogy** (customer = client, waiter = server, order = request, food = response) and the reveal that **a server is just a computer with a job** (roles depend on the job, not the machine).

## Common misconceptions (and the fix)
- "Servers are always huge machines." → Fix: your router acts as a server.
- "A computer is only ever one role." → Fix: the file-sharing example (laptop becomes a server).
- Request vs. response mixed up. → Fix: client sends the request; server sends the response.

## Pacing tips
- The `ping`/website lab needs internet; if unavailable, use the browser step alone.
- End by pointing forward: "You now know what a computer is — next we ask *why connect them?*"

## How CompTIA tests it
Every service (web, DNS, DHCP, file, mail) is a server providing to clients. This framing repeats through the whole exam.

## Support ideas
- Role-play: two learners pass a "request" note and a "response" note.

## Extension ideas
- List five servers used today (web, video, email, maps, app store).

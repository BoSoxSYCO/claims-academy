# Teaching Notes — NA-M02-L01 "Files, Folders, and How Windows Organizes Them"

> 🔒 Instructor materials. Pairs with the lesson and `wb-02-01-answers.md`.

## Objective in one line
Learners can define file/folder, read a file path, and create a folder in File Explorer.

## Where this sits
First lesson of Module 02 (Windows & the Command Line). Builds on 01-02 (storage) and 01-04 (OS). Sets up the command line, where navigating folders is the first skill. Time: ~25 min + ~40 min worksheets/lab.

## The anchor
The **filing-cabinet analogy** (cabinet = drive, drawer/folder = folder, paper = file, label = path) and reading a path **left to right**.

## Common misconceptions (and the fix)
- File vs. folder confusion. → Folder holds things; a file *is* the thing. Point at icons.
- Reading paths backward. → Always left to right: drive → folders → file.

## Pacing tips
- The `NetworkAcademy` folder they create becomes the course home base — have them keep it and add a `Module-02` subfolder in homework.
- Keep it to the C: drive and personal folders; don't wander into system folders.

## How CompTIA tests it
Indirect but foundational: tools, configs, and logs live at known paths; comfort here speeds every later hands-on lab (and the CLI lessons next).

## Support ideas
- Trace the path in the address bar with a finger while saying each folder aloud.

## Extension ideas
- Create one subfolder per module inside NetworkAcademy.

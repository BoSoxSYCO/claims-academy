# Teaching Notes — NA-M01-L01 "What Is a Computer?"

> 🔒 Instructor materials. Not for the student view. Pairs with the lesson and `wb-01-01-answers.md`.

## Objective in one line
Learners can define a computer and name its three jobs: input → processing → output.

## Where this sits
First real teaching lesson after Orientation. It is the conceptual floor for the entire course — every later device (server, switch, router) is framed as "a special kind of computer." Time: ~20 min lesson + ~40 min worksheets/lab.

## The anchor
The **kitchen analogy** is the whole lesson. If a learner leaves remembering only "ingredients → recipe → meal = input → processing → output," the lesson succeeded. Spend your teaching energy there.

## Common misconceptions (and the fix)
- **"Only laptops/desktops are computers."** → Fix with the in→work→out rule; show a phone, a router, a smart TV.
- **"Computers think for themselves."** → Fix with the recipe idea: no recipe, no meal; no program, no action.
- **Input vs. output mix-up.** → "Input goes *in* to the computer; output comes *out* to you." Have them point at the keyboard (in) and screen (out).

## Pacing tips
- Don't drift into CPU, RAM, or storage detail — that is **Lesson 01-02**. Naming them once (kitchen counter = memory, pantry = storage) is enough; promise the deep dive next lesson.
- The hands-on lab is deliberately tiny and safe (Notepad + System page). Its only job is to let learners *see* input and output on their own machine.

## How CompTIA tests it
Never asked directly on the exam. But the exam constantly treats servers, routers, and switches as computers with a special role. Plant that seed here so later modules feel familiar, not foreign.

## Support ideas (struggling learners)
- Have them physically point to objects and say "in, work, out" aloud.
- Use the everyday-computers photo (`img-01-01-everyday-computers-01.jpg`) as a talking point.

## Extension ideas (fast finishers)
- Find five "hidden" computers around the home and note each one's input and output.
- Explain the analogy to a family member and report back how it went.

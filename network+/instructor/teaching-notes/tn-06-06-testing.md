# Teaching Notes — NA-M06-L06 "Cable Testing and Common Physical Problems"

> 🔒 Instructor materials. Pairs with the lesson and `wb-06-06-answers.md`.

## Objective in one line
Learners name common cable faults (open/short/miswire/split pair/attenuation/EMI), the test tools, and the check-basics-first order.

## Where this sits
Sixth and final lesson of Module 06 — the capstone. Pulls together cable (06-01), connectors (06-02), and wiring (06-04). Objectives 1.5 and 5.2 (troubleshooting). Feeds Module 07 (switches). Time: ~28 min + ~40 min worksheets/lab.

## The anchor
**A doctor's checkup.** Check the pulse (continuity) and simple vitals first; only run deeper tests if needed. A cable tester is the stethoscope.

## Common misconceptions (and the fix)
- "A link light means the cable is perfect." → Fix: a split pair can light and still error; use a tester.
- "Start with the fancy tools." → Fix: check link light, re-seat, and swap first.
- "It must be the device." → Fix: swap a known-good cable to isolate cable vs. device.
- "Length doesn't matter." → Fix: attenuation limits twisted pair to ~100 m.

## Pacing tips
- The check-the-basics lab (6.6.E) is the payoff — everyone runs the real "no link" routine.
- Demo a cable tester lighting each pin and a kinked cable if available.

## How CompTIA tests it
Fault identification (open/short/miswire/split pair/attenuation/EMI) and the right tool (cable tester vs. tone generator); troubleshooting order.

## Support ideas
- Physically walk the 6-step order out loud each time a "no link" comes up.

## Extension ideas
- Loopback plugs, cable certifiers, and OTDR (fiber) for fast learners.

## Quiz 4.3.Q — Knowledge Check (10 pts)

1. **B** — LAN = Local Area Network.
2. **C** — A long-distance network is a WAN; the internet is the biggest WAN.
3. **C** — Phone-to-earbuds over Bluetooth is a PAN (a personal area network).
4. **B** — A WLAN is a LAN that uses Wi-Fi instead of cables.
5. **C** — A MAN covers a city (metropolitan = city).
6. **False.** Good answer: the internet spans the whole world, so it is a WAN, not a LAN.
7. **B** — Smallest to largest: PAN, LAN, MAN, WAN.
8. PAN → **B**, MAN → **C**, WAN → **A**.
9. **LAN** (a network in one building/place).
10. Joined at home = **LAN** (over Wi-Fi, the **WLAN**); the request to another country crossed a **WAN** (the internet).

**Scoring:** 1 pt each. Pass = 8/10 (80%).

## Worksheet 4.3.D — Short answer (20 pts)

1. LAN = one place (home/office); WAN = long distance (internet). *(idea /3, why /2)*
2. A WLAN is a LAN that uses Wi-Fi instead of cables — same place, no wires. *(idea /3, why /2)*
3. Any true PAN, e.g., phone ↔ Bluetooth earbuds; it's tiny and around one person. *(idea /3, why /2)*
4. PAN < LAN < MAN < WAN; the order is by size/distance covered. *(idea /3, clarity /2)*

## Quiz 10-05 — answers & explanations

**1. Strongest study method? → B) Active recall.**
Quizzing yourself covered up forces retrieval, which builds memory. Rereading (A), highlighting (C), and copying once (D) feel productive but are weak — they build recognition, not recall.

**2. Chunking means → B) Grouping ports by job.**
Chunking bundles small facts into a few buckets (web, mail, remote, files, services). A, C, and D are not chunking.

**3. Spaced repetition means → B) Reviewing at growing gaps over several days.**
Spacing beats cramming. A, C, and D are cramming or no review.

**4. Fix for swapping SSH/Telnet → B) A mnemonic.**
A hook ("SSH 22 = too secure") separates the two. Giving up (A), rereading (C), or one-time study (D) won't fix a mix-up.

**5. Both directions → C) Number → protocol AND protocol → number.**
The exam asks both ways, so practice both.

**6. True or false — rereading is most effective. → FALSE.**
Rereading builds recognition, not recall; active recall + spacing is far stronger. Accept any answer that says false and names recall/spacing.

**7. Best spacing schedule → B) Today, tomorrow, +2 days, +4 days, +1 week.**
Growing gaps = spaced repetition. A and C are cramming; D is too sparse for one exam.

**8. Matching → Chunking = C; Active recall = A; Mnemonic = B.**
Full credit requires all three.

**9. Fill in the blank → flashcard.**

**10. Scenario (sample full-credit answer):**
Chunk the three mail ports as one group (SMTP 25 send, POP3 110, IMAP 143 receive). Make flashcards and use **active recall** both directions. **Space** reviews: today, tomorrow, +2, +4, +7 days. Add a **mnemonic** (SMTP 25 sends; 25 → 110 → 143 climbs as you receive). Award credit for naming all four habits applied to the mail ports.

**Score band:** 9–10 ✅ · 7–8 🟡 · 5–6 🟠 · <5 🔴 reteach the four habits with a live covered-up quiz.

## Worksheet 10.5.D — Short Answer (4 pts each)

1. Rereading builds **recognition** — you know it when you see it — but not **recall**. The exam asks for recall cold, so rereading gives false confidence.
2. Chunking = grouping into buckets: **web, mail, remote, files, services**. Learn one group at a time.
3. Quiz **number → protocol** (443 → HTTPS) and **protocol → number** (HTTPS → 443). Accept any correct example each way.
4. Any growing-gap plan, e.g., today, tomorrow, +2, +4, +7 days.
5. Any sensible, personal hook tied to a real port (e.g., "SMB 445 = Share My Business"). Full credit for a clear explanation.

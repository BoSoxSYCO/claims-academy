## Worksheet 3.4.C — Byte to hex (20 pts)

For `10110010`:
1. `1011`  2. `0010`  3. 11  4. 2  5. **B**  6. **2**  7. **B2**.
**Why (+2):** 4 bits have exactly 16 patterns (0–15), which matches the 16 hex digits — one hex digit per nibble.

## Worksheet 3.4.D — Short answer (20 pts)

1. Hex is a base-16 shorthand for binary; it exists to write bytes in fewer characters. *(idea /3, why /2)*
2. Four bits reach 0–15, but we only have digits 0–9, so A–F fill in for 10–15. *(idea /3, why /2)*
3. One hex digit = 4 bits (a nibble); two hex digits = one byte. *(idea /3, why /2)*
4. `3C`: 3 = `0011`, C = `1100` → `00111100`. *(idea /3, steps /2)*

## Worksheet 3.4.E — Vocabulary review (20 pts)

- **Part A:** Hexadecimal = base-16 (0–9, A–F); Nibble = 4 bits; Base 16 = a 16-symbol system; MAC address = a device's hardware ID in hex.
- **Part B:** 1. Nibble 2. Hexadecimal 3. MAC address.
- **Part C:** F = `1111`; `1100` = C.
- **Part D:** 8 bits in a byte; `11000000` = 192.

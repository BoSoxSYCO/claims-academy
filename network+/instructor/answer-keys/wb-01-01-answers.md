> 🔒 **Instructor / self-check only.** Covers Quiz 1.1.Q and Worksheets 1.1.A–1.1.G.
> Every answer includes *why*. Open-ended items include a model answer + "a good answer includes…"

## Quiz 1.1.Q — Knowledge Check (10 pts)

1. **B** — A computer follows instructions to turn input into output. *A/C/D describe only one small use, not what a computer is.*
2. **B** — Input, processing, output. *The others are actions or button names, not the three core jobs.*
3. **False.** A good answer says: a computer can only follow the instructions in its **program**; it cannot decide on its own.
4. **A** — A home router. *A router is a special computer. A brick, mug, and pencil have no input→process→output.*
5. **C** — Input. *Typing sends information into the computer.*
6. **B** — Output. *The screen shows the result back to you.*
7. **B** — The program (instructions). *The recipe tells the cook what to do, like a program tells a computer.*
8. Input → **B**, Output → **C**, Program → **A**.
9. **Processing** (also accept "Work"). *In → Processing → Out.*
10. Model answer: "A smart TV is a computer because it takes **input** (your remote presses), does **processing** (finds the show), and gives **output** (the picture and sound). It just doesn't look like a laptop." *A good answer names at least the input→process→output idea.*

**Scoring:** 1 pt each. Pass = 8/10 (80%).

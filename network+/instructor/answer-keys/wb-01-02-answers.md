## Quiz 1.2.Q — Knowledge Check (10 pts)

1. **B** — The CPU follows instructions and does the work.
2. **C** — RAM is fast but temporary; it clears at power-off.
3. **B** — Storage keeps files with the power off.
4. **False.** Good answer: RAM is fast and temporary (work space); storage is slower and permanent (keeps files). They are different.
5. **C** — Desktop surface = RAM (space for what you're using now).
6. **B** — Filing cabinet = storage (keeps things long-term).
7. **B** — RAM. Too little RAM makes many-open-programs feel slow.
8. CPU → **B**, RAM → **C**, Storage → **A**.
9. **permanent** (accept "kept even when off").
10. Yes, it's still there; **storage** kept it, because storage is permanent and is not wiped when the power is off.

**Scoring:** 1 pt each. Pass = 8/10 (80%).

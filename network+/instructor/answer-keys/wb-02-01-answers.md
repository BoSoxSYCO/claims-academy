## Quiz 2.1.Q — Knowledge Check (10 pts)

1. **B** — A file is one saved item of information.
2. **B** — A folder is a container for files and other folders.
3. **A** — directory.
4. **B** — A path tells you which folders to open to reach a file.
5. **C** — The C: drive is opened first (paths read left to right).
6. **True.** Good answer: folders can hold other folders, which makes the tree.
7. **B** — File Explorer.
8. File → **B**, Folder → **A**, Path → **C**.
9. **backslash** ( \ ).
10. Ask **"Which folder (or path) did you save it in?"** — knowing the location/path lets you go straight there in File Explorer.

## Quiz 4.6.Q — Knowledge Check (10 pts)

1. **B** — Bandwidth is the most data a link can carry (its capacity).
2. **B** — Throughput is what actually gets through, usually less than bandwidth.
3. **C** — Latency is measured in milliseconds (ms).
4. **C** — Latency is a time (a delay); bandwidth and throughput are amounts.
5. **C** — The real, measured 180 Mbps is throughput; the 300 Mbps plan is bandwidth.
6. **False.** Good answer: high latency is a delay; adding bandwidth (capacity) does not shorten the trip time.
7. **C** — The `time=` value in ping is latency.
8. Bandwidth → **B**, Throughput → **C**, Latency → **A**.
9. **milliseconds (ms)**.
10. **Latency.** Why: downloads are fine (throughput/bandwidth ok), but calls freeze because of delay — high latency (and jitter) hurts real-time calls.

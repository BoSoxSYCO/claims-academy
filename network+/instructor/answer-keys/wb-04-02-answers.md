## Quiz 4.2.Q — Knowledge Check (10 pts)

1. **B** — A node is any device that connects to a network.
2. **B** — A link is the connection between two nodes.
3. **C** — A laptop is a node (a cable and a Wi-Fi signal are links; a road is an analogy).
4. **B** — A cable link is a wired link.
5. **B** — A Wi-Fi link is a wireless link.
6. **True.** Good answer: a phone connects to the network, so it's a node — Wi-Fi is just the link it uses.
7. **B** — A road = a link.
8. Node → **C**, Link → **A**, Wireless link → **B**.
9. **line** (a line/edge).
10. Nodes: router, laptop, phone. The laptop's cable is a **wired** link; the phone's Wi-Fi is a **wireless** link.

**Scoring:** 1 pt each. Pass = 8/10 (80%).

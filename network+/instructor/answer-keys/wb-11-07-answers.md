## Quiz 11-07 — answers & explanations

**1. Wi-Fi 6? → C) 802.11ax.**
n = Wi-Fi 4 (A), ac = Wi-Fi 5 (B), b is an old standard (D).

**2. Farther but slower band → A) 2.4 GHz.**
5 GHz (B) is faster but shorter range. They differ (not C/D).

**3. Non-overlapping 2.4 GHz channels → B) 1, 6, 11.**
Adjacent channels (A) overlap; C is wrong; not all channels (D) are clear.

**4. Current best security → D) WPA3.**
WEP (A) is broken, WPA (B) is weak, WPA2 (C) is strong but WPA3 is newer/best.

**5. Broken security → A) WEP.**
WPA2 (B) and WPA3 (C) are safe. "None" (D) is wrong — WEP is broken.

**6. True or false — hiding SSID = truly secure. → FALSE.**
Hiding the network name is minor and easily bypassed; real security comes from WPA2/WPA3 and a strong passphrase. Accept any answer that says false and names WPA2/WPA3.

**7. Network name → C) SSID.**
Not a channel (A), band (B), or gateway (D).

**8. Matching → 802.11n = C (Wi-Fi 4); 802.11ac = A (Wi-Fi 5); 802.11ax = B (Wi-Fi 6).**
Full credit requires all three.

**9. Fill in the blank → 5 (GHz).**

**10. Scenario (sample full-credit answer):**
(1) **Change WEP to WPA2 or WPA3** — WEP is broken, so it's both insecure and often forces slow legacy rates. (2) **Change the 2.4 GHz channel from 3 to 1, 6, or 11** — channel 3 overlaps neighbors; a non-overlapping channel cuts interference and dropouts. (Bonus: use 5 GHz nearby for speed.) Award credit for the security upgrade + the non-overlapping channel, each with a reason.

**Score band:** 9–10 ✅ · 7–8 🟡 review bands/security · 5–6 🟠 redo standards table · <5 🔴 reteach with the highway/lane analogy.

## Worksheet 11.7.D — Short Answer (4 pts each)

1. **Wi-Fi 4 = 802.11n, Wi-Fi 5 = 802.11ac, Wi-Fi 6 = 802.11ax.**
2. **2.4 GHz** reaches farther and through walls; **5 GHz** is faster (with shorter range). Accept either strength each.
3. On 2.4 GHz the channels overlap; only 1, 6, and 11 are spaced far enough apart to avoid interfering.
4. **WEP < WPA < WPA2 < WPA3.** Use **WPA2 or WPA3**; avoid **WEP** (and old WPA).
5. Bands are **highways** (2.4 GHz long/slow, 5 GHz short/fast); channels are **lanes** you pick so signals don't collide.

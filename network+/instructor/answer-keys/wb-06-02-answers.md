# Answer Key — Lesson NA-M06-L02 "Connectors and Jacks (RJ45, Keystones)"

> 🔒 **Instructor / self-check only.** Covers Quiz 6.2.Q and Worksheets 6.2.A–6.2.G.

**Key facts:** Connector = plug · Jack = socket · RJ45 = 8-pin Ethernet plug (locking tab) · RJ11 = smaller phone plug.

---

## Quiz 6.2.Q — Knowledge Check (10 pts)

1. **B** — A connector is the plug on the end of a cable.
2. **B** — A jack is the socket a connector plugs into.
3. **D** — An RJ45 has 8 pins (one per wire).
4. **B** — Twisted-pair Ethernet uses the RJ45.
5. **B** — RJ11 is smaller and used for phones.
6. **True.** Good answer: a broken tab lets the plug wiggle loose, so the link cuts in and out.
7. **A** — A keystone jack is a snap-in jack module for a wall plate or panel.
8. RJ45 → **B**, Patch panel → **A**, Patch cable → **C**.
9. **tab** (the locking tab).
10. The **locking tab** is likely broken; fix it by replacing the patch cable (or re-terminating the connector).

**Scoring:** 1 pt each. Pass = 8/10 (80%).

## Worksheet 6.2.D — Short answer (20 pts)

1. A connector is the plug (male) on a cable; a jack is the socket (female) it plugs into. *(idea /3, why /2)*
2. RJ45 has 8 gold pins and a plastic locking tab that clicks into the jack. *(idea /3, why /2)*
3. RJ45 is clearly wider (8 pins); RJ11 is smaller with fewer pins (phone). *(idea /3, why /2)*
4. A patch panel is a set of jacks where in-wall cables end; short patch cables connect it to the switch, so changes are easy and tidy. *(idea /3, why /2)*

## Quiz 1.5.Q — Knowledge Check (10 pts)

1. **B** — Hardware = the physical parts you can touch.
2. **B** — Software = the instructions and programs the computer runs.
3. **C** — The keyboard is hardware.
4. **D** — Windows is software.
5. **False.** Good answer: software needs hardware to run on; instructions can't do anything without a machine.
6. **B** — "Can I touch it?"
7. **B** — Firmware = software built into a device, like a switch.
8. RAM → **B**, Web browser → **A**, Ethernet cable → **C**.
9. **runs** (software *runs* on hardware).
10. Most likely a **hardware** problem (no power/lights at all points to the physical device or its power), not the settings/software.

**Scoring:** 1 pt each. Pass = 8/10 (80%).

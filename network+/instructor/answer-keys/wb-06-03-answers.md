## Quiz 6.3.Q — Knowledge Check (10 pts)

1. **B** — Fiber carries data as light.
2. **B** — The core carries the light.
3. **B** — The cladding reflects stray light back into the core.
4. **B** — Single-mode has a thin core and a laser, for long distances.
5. **B** — Multimode suits shorter runs inside a building/data center.
6. **True.** Good answer: fiber carries light, not electricity, so electrical noise (EMI/crosstalk) doesn't affect it.
7. **B** — Fiber goes much farther and ignores EMI (also faster, more secure).
8. Core → **B**, Single-mode → **A**, Multimode → **C**.
9. **mode**.
10. **Single-mode** (reaches km-scale distances); multimode is limited to a few hundred meters, so it can't span 20 km.

## Quiz 4.5.Q — Knowledge Check (10 pts)

1. **B** — The server provides files and services to many clients.
2. **A** — In P2P, all computers are equal and share directly.
3. **B** — Central control makes client-server easy to manage and back up.
4. **B** — The server is a single point of failure; if it goes down, all clients lose the service.
5. **C** — A peer can be both a client and a server at once.
6. **False.** Good answer: P2P has no central server — the peers share directly as equals.
7. **B** — Your browser is the client, asking a web server for the page.
8. Client-server → **B**, Peer-to-peer → **A**, Single point of failure → **C**.
9. **client** (the client asks the server).
10. **Peer-to-peer.** Why: with only two laptops, they can share directly with no server to buy or run — cheap and simple.

**Scoring:** 1 pt each. Pass = 8/10 (80%).

**Why (+2):** in P2P every peer is equal and shares directly, so there is no single computer everyone depends on.

## Worksheet 4.5.D — Short answer (20 pts)

1. Client-server has one server serving many clients; P2P has equal peers sharing directly with no server. *(idea /3, why /2)*
2. Strength: central control, easy to manage/back up (and scales). Weakness: the server is a single point of failure (and costs money). *(idea /3, why /2)*
3. With few devices there is nothing to buy or run — peers share directly, so it is cheap and simple. *(idea /3, why /2)*
4. A peer can ask another peer for a file (acting as client) while also sharing its own files (acting as server) at the same time. *(idea /3, why /2)*

## Quiz 3.2.Q — Knowledge Check (10 pts)

1. **C** — 8 bits in a byte.
2. **A** — 1, 2, 4, 8 (reading right to left).
3. **C** — 255 is the largest one byte can hold.
4. **A** — Each place is worth 2× the one to its right.
5. **B** — `00001010` = 8 + 2 = 10.
6. **True.** Good answer: add a place value only when its bit is 1; skip the 0s.
7. **C** — `11000000` = 128 + 64 = 192.
8. Byte → **B**, Place value → **A**, Decimal → **C**.
9. **255**.
10. **160** = 128 + 32 → turn on the 128 and 32 places → `10100000`.

**Scoring:** 1 pt each. Pass = 8/10 (80%).

## Worksheet 3.2.C — Fill the place-value row (20 pts)

Place values: 1. 128  2. 64  3. 32  4. 16  5. 8  6. 4  7. 2  8. 1.
- `11000000`: the 128 and 64 places are on; 128 + 64 = **192**.
**Why (+2):** biggest on the left mirrors how we already write numbers (like hundreds before ones), so it's easy to read.

## Worksheet 3.2.D — Short answer (20 pts)

1. A byte is a group of 8 bits. *(idea /3, why /2)*
2. Decimal places grow ×10; binary places grow ×2 (double). *(idea /3, why /2)*
3. Eight coins worth 128…1; pick which coins are "in" (1) to make any value 0–255. *(idea /3, clarity /2)*
4. `10010000`: 128 place on + 16 place on → 128 + 16 = **144**. *(idea /3, steps /2)*

## Worksheet 3.2.E — Vocabulary review (20 pts)

- **Part A:** Byte = 8 bits; Place value = what each bit position is worth; Decimal = our 0–9 system; Bit = a single 1 or 0.
- **Part B:** 1. Byte 2. Decimal 3. Place value.
- **Part C:** 128, 64, 32, 16, 8, 4, 2, 1.
- **Part D:** two states are simple/reliable; a bit is a single 1 or 0.

## Worksheet 3.2.G — Hands-on observation (25 pts)

- Read: `00000100` = 4; `00010001` = 17; `11111111` = 255.
- Build: 16 = `00010000`; 192 = `11000000`; 200 = `11001000`. *(reading /9, building /12)*
- 200 = 128 + 64 + 8; biggest byte = 255; matches confirmed. *(interpretation /4)*

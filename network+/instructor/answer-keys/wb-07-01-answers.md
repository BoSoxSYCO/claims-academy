# Answer Key — Lesson NA-M07-L01 "Hubs, Switches, Routers — What's the Difference?"

> 🔒 **Instructor / self-check only.** Covers Quiz 7.1.Q and Worksheets 7.1.A–7.1.G.

**Device → layer → address:** Hub = L1 (no address, repeats to all) · Switch = L2 (MAC, one port) · Router = L3 (IP, connects networks).

---

## Quiz 7.1.Q — Knowledge Check (10 pts)

1. **B** — A hub repeats every signal out all ports.
2. **B** — A switch uses the MAC address to reach the right port.
3. **B** — A router connects different networks (home to internet).
4. **B** — A switch works at Layer 2.
5. **C** — A router works at Layer 3.
6. **False.** Good answer: a switch learns MAC addresses and sends each frame to only the one right port (a hub sends to all).
7. **B** — Hubs repeat to everyone, causing noise and collisions; switches replaced them.
8. Hub → **B**, Switch → **A**, Router → **C**.
9. **switch** (router + switch + Wi-Fi AP in one).
10. **A switch** — it sends each frame only to the right port (fast, few collisions); a hub would repeat every message to all five and cause noise.

**Scoring:** 1 pt each. Pass = 8/10 (80%).

## Worksheet 7.1.C — Label the diagram (20 pts, 4 each)

1. Hub, Layer 1 2. Switch, Layer 2 3. Router, Layer 3. **Q4:** the hub. **Q5:** the switch.
**Why (+2):** a switch sends each frame only to the destination port, so devices don't all hear every message and there are far fewer collisions.

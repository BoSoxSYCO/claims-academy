## Quiz 3.5.Q — Knowledge Check (10 pts)

1. **B** — 4 bytes in an IPv4 address.
2. **C** — Each octet is 0–255.
3. **B** — MAC is written in hexadecimal.
4. **C** — 6 bytes in a MAC address.
5. **A** — One byte of an IP = an octet.
6. **False.** Good answer: an octet is one byte, so its maximum is 255 — 300 is impossible.
7. **B** — `1A` is one byte (two hex digits = 8 bits).
8. IPv4 address → **C**, MAC address → **A**, Octet → **B**.
9. **32** bits (4 bytes × 8).
10. 192 = `11000000`; it can't be over 255 because one octet is a single byte, and a byte's maximum is 255.

**Scoring:** 1 pt each. Pass = 8/10 (80%).

## Worksheet 3.5.C — Label the addresses (20 pts)

- 1. 192 = `11000000`  2. 168 = `10101000`  3. 1 = `00000001`  4. 10 = `00001010`.
- IP: 4 bytes, 32 bits.
- MAC: 6 pairs (bytes); each pair = 8 bits; total 48 bits.
**Why (+2):** an IP is four decimal numbers with dots; a MAC is six hex pairs with colons/dashes.

## Worksheet 3.5.D — Short answer (20 pts)

1. Four parts (octets), each a byte 0–255, written in decimal with dots. *(idea /3, why /2)*
2. Six bytes written in hex (pairs of hex digits). *(idea /3, why /2)*
3. Binary/hex are the letters; addresses (IP, MAC) are the words built from them. *(idea /3, clarity /2)*
4. It's an **IP** address — four decimal numbers separated by dots (a MAC would be six hex pairs). *(idea /3, why /2)*

## Worksheet 3.5.E — Vocabulary review (20 pts)

- **Part A:** IPv4 address = four dotted decimal bytes; Octet = one byte of an IP; MAC address = six hex bytes (hardware ID); Byte = 8 bits.
- **Part B:** 1. Octet 2. MAC address 3. IPv4 address.
- **Part C:** IP = 4 bytes; MAC = 6 bytes.
- **Part D (module recall):** two states are simple/reliable; 255 = `11111111`; one hex digit = 4 bits.

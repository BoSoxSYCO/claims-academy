## Quiz 2.4.Q — Knowledge Check (10 pts)

1. **B** — ipconfig shows your network address.
2. **C** — ping tests if you can reach a device.
3. **B** — Default Gateway = your router.
4. **B** — cd moves into a folder.
5. **A** — dir lists files/folders where you are.
6. **True.** Good answer: "Reply from" means the device sent an answer back, so it's reachable.
7. **B** — `cd ..` goes up one folder.
8. ipconfig → **C**, ping → **A**, dir → **B**.
9. **space**.
10. **`ipconfig`** (find your address and gateway) and **`ping`** the gateway/`8.8.8.8` (test reachability): ipconfig shows whether you even have an address; ping shows how far you can reach.

## Worksheet 2.4.D — Short answer (20 pts)

1. ipconfig shows network settings; two useful lines: IPv4 Address and Default Gateway. *(idea /3, why /2)*
2. ping tests reachability; "Reply from" = success, "Request timed out" = no answer. *(idea /3, why /2)*
3. cd moves you into a folder; dir lists what's in the current folder. *(idea /3, why /2)*
4. Run ipconfig (do I have an address/gateway?), then ping the gateway (router reachable?), then ping 8.8.8.8 (internet reachable?) — the first failure points to the problem. *(idea /3, steps /2)*

## Quiz 1.6.Q — Knowledge Check (10 pts)

1. **B** — A client asks for something.
2. **B** — A server provides something when asked.
3. **B** — Your laptop is the client when the browser loads a page.
4. **B** — The client's ask is the request.
5. **B** — The server's answer is the response.
6. **False.** Good answer: a server is any computer doing a "provide" job; it can be an ordinary machine (even your router).
7. **B** — The waiter = the server.
8. Client → **C**, Server → **A**, Request → **B**.
9. **server** (the router acts as a server).
10. Your laptop is acting as the **server**, because it is *providing* the file to the friend's computer (which is the client). The role changed because it depends on the job.

**Scoring:** 1 pt each. Pass = 8/10 (80%).

## Worksheet 1.6.C — Label the diagram (20 pts, 5 each)

1. Client 2. Server 3. Request 4. Response.
**Why (+2):** two arrows because the client asks (request out) and the server answers (response back) — a round trip.

## Worksheet 1.6.D — Short answer (20 pts)

1. Client asks; server provides. *(idea /3, why /2)*
2. Customer = client; waiter = server. *(idea /3, clarity /2)*
3. A server is any computer given a "provide" job — e.g., a home router providing addresses. *(idea /3, why /2)*
4. Browsing: laptop = client (asking). Sharing a photo: laptop = server (providing). The role changed because it depends on the job, not the machine. *(idea /3, why /2)*

- **Part D (Module recall):** three jobs = input, processing, output; RAM = fast/temporary, storage = slower/permanent; OS = runs programs and manages hardware.

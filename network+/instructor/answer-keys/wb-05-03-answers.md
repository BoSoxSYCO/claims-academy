## Quiz 5.3.Q — Knowledge Check (10 pts)

1. **B** — The TCP/IP model has 4 layers.
2. **D** — The bottom TCP/IP layer is Network Access.
3. **B** — The Internet layer maps to OSI Layer 3 (Network).
4. **C** — The Transport layer maps to OSI Layer 4.
5. **D** — The Application layer covers OSI Layers 5, 6, and 7.
6. **False.** Good answer: they don't compete — both describe the same networking; OSI is still used as the detailed teaching/reference model.
7. **B** — IP lives in the Internet layer.
8. Network Access → **B**, Internet → **A**, Application → **C**.
9. **Network Access** (the bottom layer).
10. **Internet layer** (OSI 3 = TCP/IP Internet); likely an addressing or routing problem (IP address or router path).

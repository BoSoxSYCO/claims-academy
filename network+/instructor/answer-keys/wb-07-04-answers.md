## Quiz 7.4.Q — Knowledge Check (10 pts)

1. **B** — An access point lets wireless devices join a wired network.
2. **B** — A modem connects your home to your internet provider.
3. **B** — A firewall allows or blocks traffic by rules.
4. **B** — A load balancer spreads traffic across several servers.
5. **B** — IDS alerts; IPS blocks.
6. **False.** Good answer: a modem connects to the ISP; a router connects networks — different jobs (often combined in one gateway box).
7. **B** — PoE provides power and data over one Ethernet cable.
8. Firewall → **C**, Access point → **A**, Proxy server → **B**.
9. **proxy** (proxy server).
10. A **load balancer** — it spreads the incoming visitors across several servers so no single server is overwhelmed.

**Scoring:** 1 pt each. Pass = 8/10 (80%).

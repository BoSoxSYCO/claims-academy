### Step 1 — Write the data (5 pts)
On a small paper, write a short message and label it **"Data."**

### Step 2 — Wrap it three times (10 pts)
Wrap the paper (or draw boxes around it) and label each wrapper:

- Wrapper 1: write **"port"** → this bundle is a ____________
- Wrapper 2: write **"IP address"** → this bundle is a ____________
- Wrapper 3: write **"MAC"** in front + **"error check"** at the end → this bundle is a ____________

### Step 3 — Send as bits (5 pts)
Slide it across the table. On the wire it travels as ____________.

### Step 4 — De-encapsulate (5 pts)
Unwrap in reverse. Write the order you removed the wrappers:

________ → ________ → ________ → back to **Data**

Did each layer **add** or **remove** its wrapper on the way up? ____________

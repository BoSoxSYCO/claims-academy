# [Module 02 · Lesson 02] Finding and Opening the Tools You'll Use

> **Unit:** Unit 1 — Computer & Digital Foundations · **Time:** ~20 min · **Equipment:** E1 (your laptop)
> **You'll need first:** Lesson 02-01 (files, folders, and File Explorer).

Windows has hundreds of tools and settings. You don't need to memorize where each one lives. You just need one skill: **searching by name.** Learn that, and you can open anything in seconds.

## 2. Introduction — why this matters

Imagine walking into a huge office building with hundreds of rooms and no signs. Finding one office would be a nightmare. Now imagine a **directory** in the lobby: type a name, and it tells you exactly where to go. Suddenly the building is easy.

Windows is that huge building. It has a settings page for almost everything, plus tools with names like Command Prompt, Task Manager, and Control Panel. Trying to find them by clicking around is slow and frustrating. But Windows has a lobby directory: the **Search box**. Type a tool's name, and Windows takes you straight to it.

Why does this matter for this course? Because you'll open the same handful of tools again and again — the terminal, network settings, Task Manager. Once you can find any tool by name, none of the later lessons will feel hard to start.

🎯 **Exam tip:** The exam won't ask "how do you open Command Prompt?" But every hands-on task you practice starts by opening a tool. Being fast at that saves you time and stress.

---

## 3. Simple explanation

The fastest way to open anything in Windows is to **search for it by name**:

1. Click the **Start** button (the Windows logo, usually bottom-left), **or** press the **Windows key**.
2. Just start **typing** the name of the tool (for example, `Command Prompt`).
3. Windows shows a list of matches. Click the one you want, or press **Enter** to open the top match.

That's it. You don't need to know which menu it hides in. You type the name, and Windows finds it.

Here are the tools you'll use most in this course:

| Tool | What it's for |
|------|---------------|
| **Settings** | Change how Windows works (including network settings) |
| **Control Panel** | Older settings area; some network tools still live here |
| **Command Prompt** | Type commands (you'll use this a lot soon) |
| **File Explorer** | See your files and folders (from Lesson 02-01) |
| **Task Manager** | See what's running and how busy the CPU/RAM are |
| **Network settings** | See and change your network connection |

Two places hold your tools:

- The **Start menu** — opens when you click Start; shows apps and search.
- The **taskbar** — the strip along the bottom; you can **pin** favorite tools there so they're always one click away.

To **pin** a tool to the taskbar: find it (by searching), right-click it, and choose **Pin to taskbar**. Now it lives on the bottom strip for quick access.

💡 **Tip:** When in doubt, press the **Windows key** and just start typing. It's the single most useful habit in Windows.

## 9. Hands-on lab

**Goal:** open three tools by searching, and pin one to your taskbar.
**Why:** you'll open these same tools throughout the course — make it fast now.

**You will need**
- Your Windows laptop (Equipment tier **E1**).
- No internet or cables needed.
- Estimated time: 8 min.

⚠️ **Before you start (safety):** You will only *open* tools and pin one. You will not change any settings inside them.

### 9a. Step-by-step instructions

1. Press the **Windows key** on your keyboard.
2. Type `Settings`. When **Settings** appears at the top, press **Enter**. It opens. Close it.
3. Press the **Windows key** again and type `Task Manager`. Open it, glance at it, then close it.
4. Press the **Windows key** again and type `Command Prompt`. **Don't press Enter yet.**
5. **Right-click** the **Command Prompt** result and choose **Pin to taskbar**.
6. Look at your taskbar (bottom strip). The Command Prompt icon is now there. Click it once to open it, then close it.

### 9b. Expected results

- Each tool opens when you search its name and press Enter.
- After step 5, a Command Prompt icon appears on your taskbar.
- ✅ **You did it if:** you opened three tools by name and pinned Command Prompt to the taskbar.

### 9c. Verify it worked

1. Find the Command Prompt icon on your taskbar. Click it — it should open.
2. Say the habit out loud: "Windows key, type the name, Enter."

### 9d. Reset / roll back

If you'd rather not keep the pin, right-click the Command Prompt icon on the taskbar and choose **Unpin from taskbar**. (Keeping it is handy for the next lessons.)

## 10. Common mistakes

| ⚠️ Mistake | What happens | How to fix / avoid it |
|-----------|--------------|-----------------------|
| Hunting through menus for a tool | Slow and frustrating | Press the Windows key and type the name instead |
| Typing in the wrong place | Nothing happens | Click Start (or press the Windows key) first, then type |
| Clicking the wrong search result | You open the wrong thing | Read the "Best match" label; pick the exact tool name |

---

## 11. Troubleshooting

| Symptom | Likely cause | Try this |
|---------|--------------|----------|
| Nothing happens when I type | The Start menu isn't focused | Press the Windows key first, then type |
| The tool isn't in the results | Name spelled differently | Try a shorter word (e.g., `cmd` for Command Prompt) |
| No "Pin to taskbar" option | Right-clicked the wrong spot | Right-click directly on the search **result** for the tool |

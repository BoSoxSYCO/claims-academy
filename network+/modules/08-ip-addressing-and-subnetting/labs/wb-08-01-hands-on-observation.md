**Goal:** find your laptop's own IPv4 address and read it in dotted-decimal notation.
**Safety:** you are only **reading** settings — change nothing.

---

### Step 1 — Open the Command Prompt (5 pts)
Click **Start**, type `cmd`, press **Enter**.

Command Prompt open? ☐ Yes ☐ No

### Step 2 — Run ipconfig (5 pts)
Type `ipconfig` and press **Enter**. Find the **IPv4 Address** line.

Your IPv4 address: ______.______.______.______

### Step 3 — Check the format (5 pts)
Count the dots and the range of each number.

Dots (should be 3): ______ &nbsp;&nbsp; Each number between 0 and ______ ?  ☐ Yes ☐ No

### Step 4 — Find the gateway (5 pts)
Read the **Default Gateway** line — that's your **router's** IP.

Default Gateway: ______.______.______.______

### Step 5 — Compare (5 pts)
Do your laptop's IP and the gateway share their **first three** numbers?

☐ Yes ☐ No &nbsp;&nbsp; (If yes, they're on the **same network** — more on why in Lesson 08-03.)

# Shared Assets

Media reused across two or more modules. Module-specific media stays inside that
module's own `assets/` folder (see [Repository Structure](../docs/REPOSITORY-STRUCTURE.md)).

- `diagrams/` — reusable concept diagrams (SVG preferred).
- `photos/` — real-world reference photos.
- `icons/` — the single consistent icon set (switch, router, PC, server, AP, firewall, cloud).
- `templates/` — starter templates for lessons, labs, quizzes, and the diagram legend.

All media follows the naming and accessibility rules in
[Naming Conventions](../docs/NAMING-CONVENTIONS.md) and the [Style Guide](../docs/STYLE-GUIDE.md).
